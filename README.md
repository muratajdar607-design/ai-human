# SANA 2 — қазақша AI & Human Detector

Қазақша мәтіннің адам мәтіндеріне немесе AI үлгілеріне көбірек ұқсайтынын машиналық оқыту арқылы бағалайтын **оқу-зерттеу жобасы**. Датасет, оны дайындау коды, үйретілген модель, тексеру есебі, Jupyter notebook және қазақша веб-интерфейс бірге беріледі.

> Модель ұпайы — авторлықтың дәлелі емес. Бұл шағын энциклопедиялық корпустағы эксперимент; кез келген қазақша мәтінге бірдей дәлдік уәде етілмейді.

**V2: 600 мәтін (300 адам + 300 AI), бастапқы 180 мәтіннен 3.33 есе үлкен.** Бастапқы датасет жаңа мақалалар және жеке авторланған AI жұптарымен кеңейтіліп, модель қайта үйретілді. Нақты көлемдер мен жаңа тақырыптардағы тест нәтижелері `reports/metrics.json` және `docs/PROJECT_REPORT.md` ішінде. Алдыңғы нұсқаның train/validation/test тақырыптары өзгертілмеді.

## VS Code-та ашу

1. ZIP архивін ноутбукке толық шығарыңыз. Python 3.11 және VS Code орнатылған болсын.
2. **File → Open Workspace from File… → `SANA.code-workspace`** таңдаңыз.
3. Python кеңейтімін орнатып, **Python: Select Interpreter → Python 3.11** таңдаңыз.
4. **Terminal → Run Task… → SANA: setup** орындаңыз. Бұл `.venv` жасап, бекітілген пакеттерді орнатады.
5. Жасалған `.venv` интерпретаторын таңдаңыз. **Run and Debug → SANA: веб-интерфейс (F5)** арқылы ашыңыз.

Толық Windows/macOS/Linux нұсқаулығы: [docs/VSCODE_GUIDE.md](docs/VSCODE_GUIDE.md). Дайын модельмен жұмыс істеу үшін GPU және AI API кілті қажет емес. Бірінші орнатуға интернет керек; мәтінді тексеру жергілікті орындалады.

## Жылдам іске қосу

**Windows:** Python 3.11 орнатылған компьютерде осы қалтадағы `start.bat` файлын екі рет басыңыз. Бірінші іске қосқанда `.venv` ортасы мен қажетті пакеттер орнатылады; интернет осы кезеңде керек. Дайын модельмен мәтін тексеру жергілікті жұмыс істейді.

**Терминал арқылы:**

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python run.py --open-browser
```

Linux/macOS-та соңғы екі командада `.venv/bin/python` қолданыңыз.

Интерфейс: **http://127.0.0.1:8765**. Порт бос болмаса: `python run.py --port 8766`. Тоқтату: терминалда `Ctrl+C`. Мәтіндер сыртқы API-ге жіберілмейді, қолданба оларды дискіге сақтамайды. Сервер тек `127.0.0.1` мекенжайын тыңдайды.

## Не жасалды?

1. Қазақша Уикипедияның ChatGPT жарияланғанға дейінгі нұсқаларынан дереккөзі көрсетілген адам мәтіндерінің анықтамалық класы жиналды.
2. Сол тақырыптар бойынша OpenAI көмекшісі AI мәтіндерін жазды. AI мәтіндері ешқашан адам мәтіні деп белгіленбейді.
3. Unicode/бос орын тазалау, қайталануды тексеру және ұқсас мәтіндерді бір топта ұстау орындалады.
4. Бір мақалаға тиесілі адам/AI жұбы бір ғана бөлікке түседі. Алдыңғы тақырыптардың бөлінуі `data/split_manifest.json` ішінде бекітілген; жаңа тақырыптар шамамен 70% train, 15% validation, 15% test болып қосылады.
5. TF-IDF белгілерімен бірнеше Logistic Regression нұсқасы салыстырылады. Ең жақсысы validation macro-F1 бойынша таңдалады; test модель таңдауға қатыспайды.
6. Таңдалған модельдің Accuracy, Macro-F1, AI Precision/Recall, адам мәтінін AI деп қате белгілеу жиілігі және confusion matrix есебі сақталады.

Нақты сандарды `reports/metrics.json`, `reports/data_audit.json` және интерфейстегі **«Модель туралы»** бетінен қараңыз. Үнемі ең жиі класты болжайтын majority baseline да есептеледі.

## Модельді қайта үйрету

Алдымен жоба қалтасына өтіп, виртуалды ортадағы Python-ды қолданыңыз:

```powershell
python scripts/prepare_dataset.py
python scripts/train.py
python -m pytest -q
python run.py
```

VS Code-та дайын **SANA: train** task-ы осы дайындау және үйрету қадамдарын орындайды. Егер `human_sources.json` немесе `ai_generated.json` өзгертілсе, алдымен `python scripts/build_corpus.py` арқылы `samples.jsonl` файлын қайта жинаңыз. `samples.jsonl` тікелей өзгертілсе, build_corpus командасын орындау оны қайта жазатынын ескеріңіз.

Үйретуден кейін ашық серверді қайта іске қосыңыз: модель мен датасет сервер жадында кэштеледі. Әдепкі random seed — 42. Бірдей деректер мен бекітілген кітапхана нұсқалары тәжірибені қайталауға мүмкіндік береді.

Жоба архивін қайта жасау: `python scripts/package_project.py`. Команда модель, raw датасет және бағалау есебінің хэштері сәйкес келетінін тексереді; `.venv`, кэштер және уақытша файлдар ZIP-ке кірмейді.

Notebook әдепкіде дайын модель мен есепті ашады; қайта үйрету үшін бірінші код ұяшығында `RETRAIN=True` қойыңыз. Notebook қолдану үшін қосымша **SANA: notebook setup** task-ын орындаңыз, `notebooks/01_kazakh_detector.ipynb` файлын ашып, `.venv` kernel-ін таңдаңыз. Қосымша notebook пакеттері қарапайым веб-интерфейсті іске қосуға қажет емес. Windows терминалында қазақша шығару қатесі болса, командаларда `python -X utf8` қолданыңыз.

## Өз дерегіңізді қосу

`data/raw/samples.jsonl` файлына әр жолда бір JSON объект жазыңыз. Міндетті өрістер: `text`, `label`, `group_id`, `source`, `source_url`, `provenance`; сондай-ақ `id`, `title`, `license`, `generator`, `created_at` өрістерін толтырыңыз. `label=0` — адам анықтамалық мәтіні, `label=1` — AI мәтіні. Кемінде 30 сөз болсын. Бір тақырыптағы түпнұсқа, AI нұсқасы, парафраз және үзінділерге **бір group_id** беріңіз.

Адам класына өзіңіз немесе келісім берген автор жазған мәтіндерді ғана қосыңыз. AI көмегімен жазылған мәтінді адам класына енгізбеңіз. Генератор, нұсқа, промпт, уақыт және дерек лицензиясын жазыңыз. Жаңартқан соң дайындау/үйрету командаларын орындаңыз. Сынақтағы мәтінді кейін train-ге ауыстырып, ескі test нәтижесін жаңа модельге телуге болмайды.

## Интерфейс және API

- **Тексеру:** кемінде 30 сөз, ең көбі 20 000 таңба; `.txt` файлын жүктеуге болады.
- **Нәтиже:** адам мәтініне ұқсас / AI мәтініне ұқсас / анық емес. 0.35–0.65 аралығы сақтық үшін анық емес ретінде беріледі; бұл шектер статистикалық калибрленбеген.
- **Датасет:** класс және бөлік бойынша сүзгі, мәтіннің дереккөзі, CSV жүктеу.
- **API:** `POST /api/predict` денесі `{"text": "..."}`. Схемалар: http://127.0.0.1:8765/docs.
- Дайын мысалдар **оқыту жиынынан алынған**; олардың нәтижесі тәуелсіз тест емес.

## Нені дәлелдемейді?

Бұл модель адамды немесе AI-ды тікелей танымайды: берілген корпустағы статистикалық айырмашылықтарды үйренеді. Бір дереккөз бен OpenAI көмекшісінің жазу мәнері стильге бейімделуге әкелуі мүмкін. Қазіргі эссе, әлеуметтік желі, машина аудармасы, адам өңдеген AI мәтіні және басқа генераторлар бөлек тексерілмеген. Орысша, латынша қазақша және аралас мәтіндер үшін сенімділік жоқ. Ұзын мәтіннің барлық бөлігі бір авторға тиесілі деген қорытынды да шығарылмайды.

Келесі ғылыми қадам: келісіммен жиналған көп жанрлы адам мәтіндері, бірнеше AI генераторы, жаңа авторлар/дереккөздер бойынша сыртқы тест, ұзындық пен тақырып теңгерімі, сенімділік аралығы және жеке калибрлеу жиыны.
